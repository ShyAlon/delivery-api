# Keep a coding prompt inside the reviewed package boundary

An explicit prompt can refer to the approved requirements and existing milestone
instructions without another model call or a second implementation plan. Add it
after the existing export approval, scope and checksum checks. Do not rewrite
README.md or spec/AGENTS.md. Hash the new member into package identity, reject a
substituted prompt even when its supplied hash matches, and preserve old retained
packages as immutable historical downloads.
