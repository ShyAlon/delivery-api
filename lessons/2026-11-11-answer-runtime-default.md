construction never passed that class to the interview host. Wiring must be
verified through the actual installer, not only direct client injection.

legacy is an explicit repair selection. Default, explicit candidate and legacy
each run Start plus Answer against owned Postgres and a fake HTTP provider.

replaced per-answer compute segments; Start and six generator segments remain.

tenant transaction. Borrow the shared restricted-login pool, read only catalogs,
and fail before install if the migration is absent.

dialog construction. The equivalent unquoted CSS attribute selector preserves
behavior without adding a gate exception.

untouched origin/main checkout. Test doubles now expose real autocommit, and
readiness tests explicitly clear unrelated prior failure state. No assertion was
removed. The remaining customer-vocabulary failure is unchanged and disclosed.
