# Test ownership before debt retirement

Old backlog descriptions can outlive their defects. Reproduce current callers
first. A shared migrated database is not isolation when one browser suite leaves
operator grants and credits behind. Give that suite its own database and prove
cleanup after failure. Construct real stores and replace only the inspected SQL
boundary rather than copying constructor state into __new__ doubles.

Do not fix a full-package browser failure by hiding the missing session: preserve
saved artifacts and translate the known absence at the typed child-read boundary.
Keep unrelated snapshot serialization errors visible. Reuse the explicit store
operation registry rather than introducing another transaction registration path.
