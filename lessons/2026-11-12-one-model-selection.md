# A script is not a model-selection architecture

The user asked why switching models required launch flags and approval. A wrapper
would have kept the duplicated choice alive. Trace the actual UI, engine default,
DB pin, child binding, producer stage budget and wire context first. One canonical
record must flow through them all. Free local execution removes paid approval,
not correctness checks. Verify native context at the transport, not just a model
card. A first-question pass misses streaming generator bugs; exercise both paths.

A model context limit alone does not disable a server's truncation policy. Send
explicit no-truncation/no-shift controls and verify a supported server version.
Keep a pre-dispatch refusal distinct from an uncertain dispatched call. When
adding mandatory acceptance scenarios, update the scenario-count guard too.
