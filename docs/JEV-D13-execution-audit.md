# JEV-D13 execution audit, October 10, 2026

This is an engineering checkpoint, not real-run authorization.

## Wired and verified
- Single exact retail formula; optional defaults/overrides; 1e9 scale and carried remainder.
- SameHostProducerWorker meter wraps the real in-process producer, including private
  revision proposal/approved continuation/successor uses of that worker.
- Separate gateway instances used by the interview bind to the same current meter.
- Provider wait union and founder input/review waits are excluded. Accepted threads
  settle through the same contribution ledger. Unresolved measurement is durable.
- Phase/token contribution keys are once-only. Compute allocation uses phase call
  share and preserves exact total. Customer task price prefers those settled ledger
  contributions rather than independently recomputing historic phase events.
- Per-phase product model is grounded in durable execution_options.model_route.
  MODEL in the attended harness remains a fixture/default; it is not product authority.
- Provider snapshot/rule/hash/source/freshness are frozen in every attempt quote.
  Public source hashes are rechecked before new admission/start/settlement. A change
  holds accounting, not silent repricing. Accepted calls are allowed to finish.
- Uniform-band interval settles actual cache-aware usage at the frozen band. Unknown
  holiday or crossing billing rule holds. Reserved ceiling is not confirmed expense.
- Old immutable payment/quote/charge scales remain historical. Explicit account
  migration refuses pending payment/provider/compute and records the conversion.
- Browser roles cannot read the private contribution/compute/migration tables.
- Config migration writes a separate candidate and preserves entered credentials.
  New runtime refuses copied legacy band/vendor/retail fields until migration review.

## Held rather than silently incomplete
- The owner's 128000 protective ceiling is not a provider-enforced input bound.
  Paid admission refuses the current adapter until this is resolved/reviewed.
- Exact-retail cloud subprocess dispatch refuses to start because its compute meter
  is not installed. The legacy local/fake paths still work; do not call them prepaid
  D13 proof. No cloud fence is lifted by this branch.
- Actual Mac Docker image build/runtime is not verified here. Wheels and exact
  package source can be rebuilt; Docker is unavailable in this environment.
- No clean Mac connected run, real PayPal payment activation, cleanup or Gate/Edit

## Known operational costs
Byte-for-byte documentation hash changes, even cosmetic ones, stop new work. The
public source checker makes two public GET requests at admission/start/settlement;
failed fetches hold. This is intentionally conservative for an attended run, not
an efficient general production pricing service. A controlled cache/semantic
snapshot change classifier can be designed separately without weakening evidence.
