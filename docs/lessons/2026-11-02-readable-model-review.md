# Loaded review is not a loading review

The owner's screenshot already contained a signed review payload. Both buttons
said Working because the shared action helper renamed and disabled both. The
export measured proposal creation at 1.911s and approval at 13.192s, with 13 DB
queries and 5.446s DB time, 1.717s checkout, no engine calls. This was saving and
readiness refresh, not a stalled model/source fetch. Exact residual server time
is not attributed without additional instrumentation.

Shared dialog actions keep names and disable only the acting button. Cancel
closes the view but does not undo an already-submitted mutation. Stage copy,
elapsed time and explicitly estimated remaining time keep waits understandable.
No fabricated exact deadline or claim that close cancelled a server operation.

The shared review renderer shows plain labels, dates, exact scaled USD-per-million
prices and complete values. Secondary source/calculation evidence remains in an
expandable section, not discarded. Scroll the whole review; never flex-shrink an
inner diff into a clipped value. A held-response browser journey proves loaded,
saving, Cancel and inline failure states, with desktop/mobile screenshots.
