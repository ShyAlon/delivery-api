# Distinguish policy exclusion from read failure

A cloud fixture must not turn intentionally unrequested execution detail into a failed read. Test exclusion and absence of requests separately from a permitted diagnostics read returning an error. Keep the error sanitized. ZIP count checks should reconcile the exported manifest and bounded rendered sections rather than pin an obsolete total. Get approval before replacing a local-only contract with the supported cloud contract; do not add a new operator feature in a fixture PR.
