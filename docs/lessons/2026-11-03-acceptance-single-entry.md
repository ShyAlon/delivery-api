A dry-run that tells the owner to add an origin variable is unfinished. Use the existing private settings boundary, identify the selected target before secrets, reuse only explicitly supplied private session evidence, and hidden-prompt only for a missing credential. Never infer a logged-in owner from an operator UUID or mint a session.

The implementation lives in the repo. req is a thin route. Acceptance readiness is one shared read-only evaluator, including existing owner-policy inspection through req preflight, not a second set of money rules. Paid execution is still separate, explicit, owner-run and ceiling-bound.
