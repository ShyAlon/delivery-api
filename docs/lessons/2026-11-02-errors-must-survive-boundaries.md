# A generic error hides the fix

The Start journey replaced specific admission and provider failures with temporary-unavailability text. The user could not tell whether to change a setting, start Ollama, or stop and reconcile a paid call.

AGENTS.md now requires the real known cause and a practical next step, with uncertainty named honestly. This rule does not claim existing runtime paths are repaired. Separate runtime tests must prove safe reasons survive child and HTTP boundaries without exposing secrets or enabling blind retries.
