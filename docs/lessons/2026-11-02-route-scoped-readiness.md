# Resolve readiness per explicit provider

Before: a missing DeepSeek default stopped a valid, independently reviewed Ollama
route. Startup, readiness and immutable task capture all used the global pin set.

Resolve each configured provider independently through the same production gateway
validator. Keep a named private reason for every refused route. Never substitute
another model, create a missing local pin, invent bounds or turn on paid dispatch.
Local prices stay exact deterministic zero and carry no vendor snapshot, retail
formula, paid key or balance reader. Local model/context/output guards remain.

An attended paid preview with only Ollama ready starts without paid authority.
Failed paid source refresh excludes that route, not the local runtime. Existing
per-generation retained reviews remain immutable, and paid admission still checks
its pinned sources before any provider request. Database/config errors are not
classified as route readiness errors and still fail loudly.
