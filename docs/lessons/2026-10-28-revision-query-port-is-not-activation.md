# A revision query port is not activation

Keep query ownership separate from revision approval and runtime activation. Convert fixed SQL and explicit write invalidation without changing journal digests, acceptance references, append-only CAS, transaction scope or feature flags. Pair a static no-bridge guard across every method with a real held-journal fence and the existing staged/private installation tests. Do not present static coverage as proof of every runtime branch, or a passing local port as permission to enable installation.
