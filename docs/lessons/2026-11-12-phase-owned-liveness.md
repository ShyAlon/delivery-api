# Select the active phase's control owner

A completed upstream session is valid history, not current generator liveness.
Read control state from the matching live phase owner, after the authorized task
lookup, on every presentation read. Never turn a durable running job row into
proof of a live process. Prove both the positive path and owner loss, including a
warm cache, a real runner lifecycle, and actual UI rendering. Keep unknown work
visible as unknown rather than hiding a real orphan behind an optimistic label.
