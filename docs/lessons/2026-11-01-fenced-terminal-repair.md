# A Stop fence is not worker completion

Stop deliberately increments task generation immediately and preserves running jobs until verified completion. Legacy session generation rebinding can leave old jobs failing the ordinary worker RLS WITH CHECK. Keep that policy and normal Stop semantics intact. A separate backend-only terminal function permits explicit force closure only for an owned job with durable Stop, strictly newer task/session generation fences and no provider/compute evidence. It sets failed and records unverified-exit override audit, never rebinds the old job or touches accounting/task visibility. Shared force plan names repair IDs in its exact confirmation so both CLI and future Back office can review the exception. New migration is required; absence fails before mutation.
