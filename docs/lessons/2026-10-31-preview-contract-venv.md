# A working pool does not mean the host pin dependencies are present

ops_venv skips refresh when psycopg_pool imports. An older host venv can therefore lack the newer declared requi-child-contract even while source smoke and database checks pass. pin-local imports production_gateway, whose request parsing needs that contract, only after loading the local model. Add both vendored contract modules to the existing step-1 fail-fast gate with the exact local wheel install command. Do not bypass gateway validation or paid activation gates.
