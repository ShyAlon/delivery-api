# Preserve typed metrics without granting a token-name exemption

Secret-key regexes catch input_tokens as well as access_token. Exempt exact
reviewed metric names only with valid numeric values, and use the same rules at
every serialization layer. A later scrubber can silently undo an earlier fix.
Test the actual downloaded ZIP, including full pagination and join identifiers.
Missing historical identifiers and provider expense must remain unknown; a close
timestamp, same token count or current price is not historical evidence.
