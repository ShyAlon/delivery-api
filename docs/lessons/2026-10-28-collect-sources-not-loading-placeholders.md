# Collect sources, not loading placeholders

A dialog can open before its independent readers finish. Scraping its rendered
text during Download everything can archive Loading or stale globals as success.
The package should fetch its own current source data and record each outcome.
Account-wide credit data and process-health readers must not claim task scope.
Count manifest read failures in the visible download result, not only outer text
section failures. Policy exclusions are not read failures.
